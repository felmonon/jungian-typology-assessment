# ml-research

Research workspace for a training-method study: data-efficient pretraining of small language models at fixed compute. It is **not part of the TypeJung app** and lives here only because this is the repository attached to the session. The plan is to move it to a dedicated repo (PLAN.md §0, Q3).

To pick up cold:
1. Read `PLAN.md`. §0 lists the open decisions; §8 is the next checklist.
2. Read the tail of `RESEARCH_LOG.md` (append-only).
3. Check `RESULTS.md` for every run so far.

Checkpoints and datasets are never committed (see `.gitignore`).
